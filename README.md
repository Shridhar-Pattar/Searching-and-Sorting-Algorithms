# Searching and Sorting Algorithms

This repository contains my implementations of fundamental searching and sorting algorithms in Java. It serves as a personal learning resource to understand how each algorithm works, analyze its time and space complexity, and practice writing clean, efficient code.

## Algorithms Included

### Searching
- Linear Search
- Binary Search

### Sorting
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

## Goals
- Learn the logic behind each algorithm.
- Understand time and space complexity.
- Compare algorithm performance.
- Improve problem-solving and DSA skills.
